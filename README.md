# Algoritmos ADS IFRS
Repositório acadêmico destinado ao armazenamento e à organização das atividades práticas e listas de exercícios da disciplina de Algoritmos do curso de Análise e Desenvolvimento de Sistemas (ADS) do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Sul (IFRS).

## Linguagem de programação
Os algoritmos e exercícios deste repositório serão desenvolvidos utilizando Portugol, por meio do ambiente Portugol Studio.

## Objetivos
* Desenvolver o raciocínio lógico e a resolução de problemas.
* Aplicar os conceitos fundamentais de algoritmos.
* Praticar estruturas de controle e organização de dados.
* Registrar e documentar as atividades desenvolvidas durante a disciplina.

## Organização
As atividades serão organizadas em diretórios, conforme os conteúdos e as listas de exercícios trabalhados ao longo da disciplina.

## Ferramentas utilizadas
* Portugol Studio
* GitHub
